# 訪問診療 開業シミュレーター

`index.html` をブラウザで開くだけで動く1ファイルのツールです。

1. 7つの質問（エリア・常勤医・夜間対応・患者層・診療日・開業時の患者・開業資金）に答える
2. 開業3年目の年間医業収入・院長の取り分・黒字化月・資金残高の最低点を表示
3. 人員・給与・家賃・患者の増え方など約40項目の前提は、回答から一般的な目安を自動で入れる。あとから1項目ずつ修正でき、修正した項目は「修正」と表示される（↺で目安に戻せる）

回答と修正内容はブラウザ（localStorage）に保存されます。点数は2024年度改定ベースの概算、エリアの人口・競合は架空のサンプル値です。
