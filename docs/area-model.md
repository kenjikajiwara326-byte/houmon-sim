# 市区町村から集患しやすさと患者数の増え方を推算するモデル（設計案 v0.1）

入力は **開業予定の市区町村（政令市は区）** と、既存のシミュレーターの体制（常勤医・24h対応・診療日）。
出力は **集患しやすさスコア（全国順位つき）**、**月ごとの新規患者数**、**患者数の推移**。

全体の流れ：

```
市区町村 → ① 診療圏を決める → ② 潜在需要 D → ③ 現在の供給 S と競合リスト
        → ④ 市場に毎月生まれる新規患者 F → ⑤ 自院の取り分 π（ハフモデル）
        → ⑥ 患者数の推移 N(t) → ⑦ 集患しやすさスコア
```

---

## 0. 記号

| 記号 | 意味 | 単位 |
|---|---|---|
| j | 診療圏に含まれる市区町村 | |
| i | 競合の医療機関 | |
| t | 開業からの月数 | 月 |
| D | 訪問診療の潜在需要（受けるべき人の数） | 人 |
| S | 現在、訪問診療を受けている人の数（＝競合の患者数の合計） | 人 |
| G | 未充足の需要 = max(0, D − S) | 人 |
| μ | 月の終了率（死亡＋入院・転医） | /月 |
| N(t) | 自院の患者数 | 人 |

---

## ① 診療圏（決定：市区町村の中心から半径16km）

```
中心 c   = 開業する市区町村の人口重心（統計局が公表。政令市は区ごと）
診療圏   = c から半径16kmの円
```

- 円の中の人口は、国勢調査の **1kmメッシュ人口（年齢別）** を足し合わせて出す。市区町村の境界にとらわれず、隣の市の人口も円に入る分だけ数える。
- 要介護認定者・施設定員など市区町村単位でしかないデータは、各市区町村の75歳以上人口のうち円に入る割合 `w_j` で按分する：
  `w_j = 円内にある j の75歳以上人口 / j の75歳以上人口`
- 競合は、所在地が円の中にある医療機関をすべて数える。
- 円の中でも遠い競合ほど紹介に効きにくいので、⑤のハフモデルでは距離で重みを下げる：
  `f(d) = exp(−d / d0)`、d0 は人口密度に応じて 4〜9km。

## ② 潜在需要 D

### 2-1. 要介護度ベース（本式）

訪問診療を受ける人のほとんどは在宅（自宅・サ高住・有料老人ホーム・グループホーム）の要介護者。
特養・老健・介護医療院の入所者は配置医がいるため除く。要介護度ごとの利用率を掛けて足し合わせ、診療圏の中にある分だけ数える。

```
D = Σ_j w_j · D_j      （w_j = 市区町村 j のうち16kmの円に入る割合。①を参照）
```

#### 利用率（実データから算出、令和6年度）

医師の居宅療養管理指導の受給者数を「訪問診療を受けている人数」の代わりに使い、要介護度ごとに割り算した。

```
u_{j,k} = 医師の居宅療養管理指導の受給者数_{j,k} ÷ 在宅の認定者数_{j,k}
在宅の認定者数 = 認定者数 − 施設サービス受給者数（特養・老健・介護医療院・地域密着型特養）
医師の分 = 全職種の受給者数（保険者別）× 全国の医師の割合 r_k（0.65〜0.87）
```

- 在宅の認定者には、サ高住・住宅型有料・特定施設・グループホームの入居者が含まれる（居宅療養管理指導を算定できるため）。居宅と施設を分けずに一つの利用率で扱う。
- 出典：介護保険事業状況報告 年報 令和6年度（保険者別の認定者数・受給者数）、介護給付費等実態統計 令和6年度（医師の割合、単一建物居住者の区分）。
- 検算：全国の医師の居宅療養管理指導 約89万人/月 ÷ NDBの在医総管＋施設総管 約104万件/月 = 0.855。残りは介護保険の認定がない患者など。
- 保険者別に求めた「現在の供給（患者住所地ベース）」と、医療施設調査の訪問診療件数（医療機関所在地ベース）の相関は 0.97。

関東313保険者の分布（%、在宅認定者数で重みづけ）：

| 区分 | 中央値 | **75パーセンタイル（基準）** | 90パーセンタイル |
|---|---|---|---|
| 要支援1 | 3.1 | **3.5** | 4.8 |
| 要支援2 | 3.6 | **4.4** | 6.2 |
| 要介護1 | 14.3 | **17.1** | 20.0 |
| 要介護2 | 22.3 | **25.6** | 28.8 |
| 要介護3 | 35.2 | **38.6** | 43.3 |
| 要介護4 | 46.6 | **50.1** | 54.1 |
| 要介護5 | 56.9 | **59.7** | 63.0 |

#### 潜在需要と現在の供給

```
D_j = Σ_k 在宅の認定者数_{j,k} × u_bench_k ÷ 0.855     … 関東の上位25%の地域なみに訪問診療が届いた場合の患者数
S_j = Σ_k 医師の居宅療養管理指導の受給者数_{j,k} ÷ 0.855  … 現在の患者数（患者の住所地ベース）
```

基準を関東の75パーセンタイルにしたのは、「訪問診療が十分に届いている地域の水準」を潜在需要とみなすため。
基準を上げ下げすると未充足の大きさが変わるので、画面で調整できるようにする。

居宅と施設入居者の内訳（画面の「居宅の割合」）は、全国の医師の居宅療養管理指導のうち「単一建物居住者1人」が占める割合（要介護度別に33〜52%）で分ける。

### 2-2. 年齢ベース（検算用）

```
D'_j = Σ_a  Pop_{j,a} · p_a      a = 65-74, 75-79, 80-84, 85-89, 90+
p_a  = 全国の年齢階級別 訪問診療受療率（NDB）
```

D と D' が ±30% 以上ずれたら、画面に「データを確認」と出す（施設が極端に多い／少ない自治体の判定にも使える）。

### 2-3. 将来の需要

社人研の地域別将来推計人口（5歳階級）で、年齢階級ごとに伸ばす。

```
D(t) = D(0) · Σ_a s_a · Pop_a(t) / Pop_a(0)
s_a = 需要のうち年齢階級 a が占める割合（2-2 の内訳から）
```

5年ごとの推計値は月単位に線形補間する。

## ③ 現在の供給 S と競合

### 3-1. 市区町村全体の供給

```
S_j = 市区町村 j の住民で、訪問診療を受けている患者数（月）
      … 厚労省「在宅医療にかかる地域別データ集」（NDBの市区町村別集計）
S = Σ_j w_j · S_j
充足率 ρ = S / D ,  未充足 G = max(0, D − S)
```

### 3-2. 競合の一覧と規模

競合の一覧は地方厚生局の施設基準の届出名簿（在支診1〜3、在支病）から作る。住所は緯度経度に変換しておく。
医療機関ごとの患者数は公表されていないので、**市区町村全体の供給 S_j を届出の種類ごとの重みで按分**して推定する。

```
n_i = S_{j(i)} · a_{τ(i)} / Σ_{i' ∈ j} a_{τ(i')}
```

| 種類 τ | 規模の重み a_τ | 質の係数 q_τ |
|---|---|---|
| 機能強化型（単独） | 8 | 1.3 |
| 機能強化型（連携） | 3 | 1.15 |
| 在支診・在支病 | 1 | 1.0 |
| 届出なしで訪問診療をしている診療所 | 0.25 | 0.6 |

届出なしの診療所の数は、医療情報ネットの「訪問診療の実施あり」から数える。
患者数が分かる競合は、ユーザーが上書きできるようにする。

## ④ 市場に毎月生まれる新規患者 F

患者は毎月 μ ≒ 3.5% が終了して入れ替わる（死亡 2.2% ＋ 入院・転医 1.3%）。
新規開業の患者は、この入れ替わりで生まれる新しい患者の一部と、まだ訪問診療を受けていない人の一部から来る。

```
F_rep(t) = μ · S(t)                         … 入れ替わりの新規
F_gap(t) = λ · G(t)                         … 未充足の人が受け始める分（λ = 3%/月）
F_grw(t) = max(0, D(t) − D(t−1))            … 需要の自然増
```

---

## ⑤ 自院の取り分 π（ハフモデル）

紹介元（病院の地域連携室・ケアマネ）が、どの医療機関を紹介するかを「魅力度 ÷ 距離」で配分する。

```
自院の魅力度  A_0(t) = q_0 · (N(t) + n_0)^α · R(t) · m_days · m_24h
競合の魅力度  A_i    = q_τ(i) · n_i^α · f(d_i)

π(t) = A_0(t) / ( A_0(t) + Σ_i A_i )
```

| 記号 | 意味 | 初期値 |
|---|---|---|
| α | 規模が大きいほど紹介されやすい効果（逓減） | 0.5 |
| n_0 | 開業直後の「見かけの規模」 | 20人 |
| R(t) | 紹介ネットワークの立ち上がり `1 − 0.8·exp(−t/τ_R)` | τ_R = 6ヶ月（相談員がいれば ×0.7） |
| m_days | 診療日の係数 | 週5=1.0 / 週6=1.1 / 毎日=1.15 |
| m_24h | 体制の係数 | なし=0.6 / 在支診=1.0 / 機能強化型=1.2 |
| q_0 | 自院の質の係数 | 体制に応じて q_τ と同じ表 |

未充足の人の取り込みでは、新しい医療機関に余力がある分だけ有利になる。

```
π_gap(t) = θ · π(t) ,  θ = 1.5（上限 1）
```

競合からの切替（24h対応がない診療所の患者が、体制の強い医療機関へ移る）：

```
F_sw(t) = σ · Σ_{i: q_i < q_0} n_i · f(d_i)      σ = 0.3%/月
```

### 居住系施設（別ルート）

施設は医療機関を丸ごと切り替えるため、個人の紹介とは別に数える。

```
Fac_in(t) = B · occ · u_R · (p_sw / 12) · π(t)  +  新設施設の定員 · occ · u_R · π(t)
B    = 診療圏の居住系施設の定員 Σ w_j · R_j
p_sw = 施設が1年間に訪問診療の医療機関を見直す確率（10%）
```

実際には施設単位でまとめて契約が決まるので増え方は階段状になるが、ここでは期待値で扱う。

## ⑥ 患者数の推移

```
I(t) = π(t) · (F_rep + F_grw) + π_gap(t) · F_gap + F_sw + Fac_in    … 月の新規患者
N(t+1) = min( C,  N(t) + I(t) − μ · N(t) )
C = 診療キャパ（既存シミュレーターの式：医師数 × 診療日 × 1日の訪問件数 ÷ 月の訪問負荷）
```

市場全体も同時に更新する（自院が増えた分だけ未充足が減る）：

```
S(t+1) = S(t) + (自院以外の新規) − μ·S(t) ,   G(t) = max(0, D(t) − S(t) − N(t))
```

### 定常状態（検算とスコアに使う）

十分時間が経ったときの患者数は、流入と終了がつり合う点になる。

```
N* ≈ I* / μ
```

例：μ = 3.5%、I* = 8人/月 なら N* ≈ 230人。

## ⑦ 集患しやすさスコア

スコアは「標準的なクリニック（在支診・常勤医1人・週5日）がこの市区町村で開業したときの定常患者数 N*_std」を
**全国の市区町村の中で順位づけしたもの（パーセンタイル）** とする。
患者数の推計と同じ式から出すので、スコアと推移グラフが食い違わない。

```
Score = 100 × ( N*_std が全国の何%の市区町村より大きいか )
表示：「78点・全国1,741市区町村中 上位22%」
```

内訳として、次の4指標もそれぞれ全国順位で表示する（どこが強み・弱みか説明するため）：

| 指標 | 式 | 意味 |
|---|---|---|
| 需給ギャップ | 1 − S / D | 訪問診療が足りていないか |
| 市場の大きさ | D | 需要の絶対量 |
| 競合の強さ | Σ A_i （N*_stdでの π の裏返し） | 近くに強い競合がどれだけいるか |
| 将来性 | D(5年後) / D(今) − 1 | 需要が伸びるか |

全国の数値がそろうまでの暫定版は、各指標を固定の区切りで0〜100点に変換して重みづけ（40/20/25/15、今のシミュレーターと同じ）。

## 計算例（架空の市、75歳以上 3.3万人）

| 項目 | 値 |
|---|---|
| 居宅 要介護1〜5（2,500/1,900/1,100/800/500人）× u | 75+95+110+144+125 = 549人 |
| 要支援 3,500人 × 0.5% | 18人 |
| 居住系施設 2,300人 × 75% | 1,725人 |
| **潜在需要 D** | **約2,290人** |
| 現在の供給 S（データ集） | 1,900人（充足率 83%） |
| 未充足 G | 390人 |
| 市場の新規 F = 3.5%×1,900 + 3%×390 + 自然増4 | 約83人/月 |
| 定常の取り分 π* | 10% |
| **自院の新規 I*** | **約8〜9人/月** |
| **定常患者数 N*** | **約230〜250人**（キャパが先に上限になることが多い） |

既存シミュレーターの「標準の新規紹介ペース 10人/月」と同じ水準になり、その値をデータから出せるようになる。

## 使うデータ

| データ | 出典 | 粒度 |
|---|---|---|
| 年齢5歳階級別人口 | 住民基本台帳人口（総務省）／国勢調査 | 市区町村 |
| 将来推計人口 | 国立社会保障・人口問題研究所 地域別将来推計人口（令和5年推計） | 市区町村 |
| 人口重心・面積 | 統計局 人口重心／国土地理院 面積調 | 市区町村 |

| 施設入所者・居住系定員 | 介護サービス情報公表システム、サ高住情報提供システム、都道府県の有料老人ホーム一覧 | 施設 |
| 訪問診療の患者数・実施医療機関数 | 厚労省「在宅医療にかかる地域別データ集」 | 市区町村 |
| 在支診・在支病・機能強化型の一覧 | 各地方厚生局 届出受理医療機関名簿 | 医療機関 |
| 訪問診療を実施する診療所 | 医療情報ネット | 医療機関 |
| がん死亡数 | 人口動態統計 | 市区町村 |

- ページは外部のAPIを呼べないので、これらは事前に加工して **市区町村ごとのJSON（約1,900行）＋競合の一覧（緯度経度つき）** としてページに同梱する。
- 政令市の介護データは市単位しかないので、区ごとの75歳以上人口の比で按分する。

## パラメータと校正

| パラメータ | 初期値 | 校正の方法 |
|---|---|---|
| u_k, u_R（利用率） | 表の値 | 全国の D 合計を NDB の実績に合わせる |
| λ（未充足の取り込み） | 3%/月 | 充足率の低い地域で、新規開業後に S が伸びた速さ |
| α, n_0, τ_R | 0.5, 20, 6ヶ月 | 開業後の患者数の実例（12ヶ月で80〜120人が目安）に合わせる |
| a_τ, q_τ | 表の値 | 施設基準の報告（様式11の3）の患者数が手に入れば更新 |
| p_sw | 10%/年 | 施設へのヒアリング |

画面ではパラメータの幅（例：λ 2〜4%、τ_R 4〜9ヶ月）で計算した **楽観・悲観のレンジ** を出す。

## 決定事項

1. 診療圏：市区町村の中心（人口重心）から半径16km → **決定**
2. 競合の規模：届出の種類で按分 → **決定**（分かる分はユーザーが上書き）
3. データの範囲：まず関東1都6県（茨城・栃木・群馬・埼玉・千葉・東京・神奈川）で試す → **決定**
